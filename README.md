ସମ୍ବଲପୁରୀ କଳା ସଂସ୍କୃତି

ଭାଷା • ସାହିତ୍ୟ • କଳା • ସଂସ୍କୃତି • ପରମ୍ପରା

ଆମ ବିଷୟରେ

ସମ୍ବଲପୁରୀ କଳା ସଂସ୍କୃତି ଏକ ସାଂସ୍କୃତିକ ଅନୁଷ୍ଠାନ। ସମ୍ବଲପୁରୀ ଭାଷା, ସାହିତ୍ୟ, କଳା, ସଂସ୍କୃତି ଓ ପରମ୍ପରାର ଉନ୍ନତି ଲାଗି ଆମେ କାମ କରୁଛୁ।

ସଂସ୍ଥାର ଉଦ୍ଦେଶ୍ୟ

- ସମ୍ବଲପୁରୀ ଭାଷାର ପ୍ରଚାର ଓ ସୁରକ୍ଷା
- ସମ୍ବଲପୁରୀ ସାହିତ୍ୟର ପ୍ରଚାର
- କଳାକାର ଓ କବିମାନଙ୍କୁ ଉତ୍ସାହିତ କରିବା
- ଆମର ପରମ୍ପରା ଓ ସଂସ୍କୃତିକୁ ଆଗକୁ ନେବା
- ସାଂସ୍କୃତିକ କାର୍ଯ୍ୟକ୍ରମ ଆୟୋଜନ
